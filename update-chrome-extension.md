## Update the Chrome extension (unpacked)

1. Open:

```
chrome://extensions
```

2. Enable:
   **Developer mode** (top-right toggle)

3. Find your extension → click:
   **Reload** (🔄)

That’s it. Updated files take effect immediately.

---

If you changed the folder location:

* Remove old entry → **Remove**
* Then **Load unpacked** → select the folder again
